# Planet-M Shop — Frontend (Next.js + BFF)
Next.js App Router, Redux Toolkit, Tailwind. BFF route handlers live in `app/api`. Product pages are server-rendered.

```bash
cp .env.local.example .env.local
npm install
npm run dev     # http://localhost:3000 (needs the backend stack behind the gateway at BACKEND_URL)
npm test
```
